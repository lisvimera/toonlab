# ToonLab — VimerArt

Espacio independiente y bitácora visual estilo Instagram para la exhibición de procesos análogos: bocetos, creación de dioramas, escultura, modelado en porcelanicrón y pintura tradicional.

## Tecnologías
- **Framework**: Next.js 16 (App Router)
- **Estilos**: Tailwind CSS v4
- **Iconografía**: Lucide React
- **Lenguaje**: TypeScript

## Ejecución Local
```bash
npm install
npm run dev
```
Abre [http://localhost:3000](http://localhost:3000) en el navegador.

## Despliegue en Subdominio
Configurar en Vercel / Netlify / Cloudflare Pages asignando el dominio personalizado:
`toonlab.vimerart.com`
